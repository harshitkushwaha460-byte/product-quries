# BIS Sahayak

### AI-Powered Assistant for Bureau of Indian Standards

**BIS Sahayak** is an AI-powered conversational assistant designed to make **Bureau of Indian Standards (BIS)** information easier to find, understand, and access.

It combines **Retrieval-Augmented Generation (RAG)** with AI and **Sarvam AI** to provide context-aware assistance, including support for **Hindi and English**, making BIS-related information more accessible to users across India.

## 🎯 Problem Statement

BIS standards, certifications, and technical information can be difficult for common users to understand.

Users may have to:

* Search through multiple documents
* Understand technical terminology
* Find the relevant standard
* Interpret lengthy information
* Switch between different sources

This creates a barrier for **consumers, manufacturers, students, and other citizens** who need BIS-related information.

### 💡 Our Solution

**BIS Sahayak** provides a conversational interface where users can simply ask their questions and receive relevant, easy-to-understand answers.

Instead of searching through large documents manually:

```text
User
  ↓
Ask BIS-related Question
  ↓
BIS Sahayak
  ↓
Retrieve Relevant Information
  ↓
RAG + AI Processing
  ↓
Context-Aware Answer
```

BIS Sahayak uses **Retrieval-Augmented Generation (RAG)** to improve the relevance of responses.

```text

                          ▼
                 ┌─────────────────┐
                 │   User Query    │

                          │

                 └────────┬────────┘
                          │
                          ▼
                 ┌─────────────────┐
                 │ BIS Knowledge   │
                 │     Base        │
                 └────────┬────────┘
                          │
                          ▼
                 ┌─────────────────┐
                 │ Relevant Context│
                 │    Retrieval    │
                 └────────┬────────┘
                          │
                          ▼
                 ┌─────────────────┐
                 │  AI Generation  │

                 └────────┬────────┘
                          │
                          ▼
                 ┌─────────────────┐
                 │ Final Response  │
                 └─────────────────┘
```

# 🇮🇳 Hindi Language Support

One of the major goals of BIS Sahayak is to make BIS information accessible to users who are more comfortable communicating in **Hindi**.

Users can ask questions such as:

> **BIS प्रमाणन क्या है?**

> **ISI मार्क का क्या मतलब है?**

> **किसी उत्पाद के लिए BIS प्रमाणन कैसे प्राप्त करें?**

BIS Sahayak can process Hindi queries and provide responses suitable for Hindi-speaking users.

---

# 🗣️ Sarvam AI

BIS Sahayak incorporates **Sarvam AI** to enhance support for Indian languages.

Sarvam AI is used as part of the project's Indian-language AI capabilities, helping BIS Sahayak provide a more accessible experience for Hindi-speaking users.
